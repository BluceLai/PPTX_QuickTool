# 05 - Add Table Of Contents Navigation Links

**What to build:** Add navigation links to the generated PPTX so readers can jump from the table of contents to section pages and return from generated pages back to the table of contents.

**Blocked by:** 04 - Generate Basic PPTX Skeleton.

**Status:** ready-for-agent

- [ ] Each table of contents entry links to the matching generated section start page.
- [ ] Each section start page includes a return-to-table-of-contents link where the layout supports it.
- [ ] Each content page includes a return-to-table-of-contents link where the layout supports it.
- [ ] Link targets remain correct when sections are reordered.
- [ ] Link targets remain correct when sections have different numbers of content pages.
- [ ] Automated verification confirms that expected navigation relationships exist.
