# 07 - Connect UI To PPTX Generation

**What to build:** Connect the desktop UI to the generation pipeline so a user can enter a document structure, choose an output location, and generate a new PPTX from the app.

**Blocked by:** 05 - Add Table Of Contents Navigation Links; 06 - Build Desktop UI Form.

**Status:** ready-for-agent

- [ ] The UI can trigger PPTX generation from the current form data.
- [ ] The user can choose an output location for the generated PPTX.
- [ ] The app blocks generation when validation fails.
- [ ] The app shows a success message with the generated file location.
- [ ] The app shows a useful error message when generation fails.
- [ ] A generated PPTX from the UI contains the expected slides and text.
- [ ] The source reference or template file is not modified during generation.
