# PPTX QuickTool 使用說明

## 工具用途

PPTX QuickTool 用來快速產生教學文件 PPTX 初稿。使用者只需要輸入 PPT 標題、章節名稱，以及需要時加入各章節底下的內文頁標題，工具就會依照公司教學文件樣板產生新的 PPTX。

產出的 PPTX 會包含：

- 封面
- 主目錄
- 各章節目錄頁
- 各章節底下的內文頁
- 主目錄到各章節的超連結
- 各章節頁的「目錄」回主目錄超連結

內文頁不會顯示回主目錄連結，方便後續直接編輯教學內容。

## 啟動方式

在專案資料夾執行：

```powershell
python scripts/run_app.py
```

如果執行時出現 `No module named 'pptx'`，代表目前 Python 環境尚未安裝 PowerPoint 套件。請先安裝專案依賴：

```powershell
python -m pip install -e .
```

## 基本操作流程

1. 在 `PPT 標題` 輸入教學文件名稱。
2. 工具會預設建立 `前言` 章節，可直接改名或保留。
3. 如需更多章節，在 `章節` 區塊下方輸入章節名稱。
4. 點選 `新增章節`。
5. 選取左側章節清單中的章節。
6. 在 `選取章節的內文頁` 區塊下方輸入內文頁標題。
7. 點選 `新增內文頁`。
8. 重複新增章節與內文頁，直到架構完成。
9. 檢查右側 `投影片預覽` 的頁面順序。
10. 確認 `樣板 PPTX`。
11. 在 `輸出位置` 選擇新 PPTX 的儲存路徑。
12. 點選 `產生 PPTX`。

產生成功後，下方狀態會顯示已產生並驗證的檔案路徑。

## 欄位說明

`PPT 標題`  
產出 PPTX 的封面標題。

`章節`  
主目錄中的主要項目。每個章節會產生一張章節頁，章節可以沒有內文頁。

`選取章節的內文頁`  
目前選取章節底下要產生的內容頁。每個內文頁標題會產生一張可編輯內容頁。

`樣板 PPTX`  
預設使用內建公司教學文件樣板。也可以點選 `選擇樣板` 改用其他 PPTX 作為樣板來源。

`輸出位置`  
新 PPTX 的儲存位置。工具只會產生新檔，不會修改樣板原檔。

## 章節操作

`新增章節`  
把輸入框中的文字加入章節清單。

`改名`  
修改目前選取的章節名稱。

`刪除`  
刪除目前選取的章節與其底下所有內文頁。

`上移` / `下移`  
調整目前選取章節在 PPTX 中的順序。

## 內文頁操作

先選取一個章節，再操作內文頁。

`新增內文頁`  
把輸入框中的文字加入目前章節。

`改名`  
修改目前選取的內文頁標題。

`刪除`  
刪除目前選取的內文頁。

`上移` / `下移`  
調整目前選取內文頁在該章節中的順序。

## 產出格式

主目錄頁會顯示完整章節與內文頁結構：

- 主章節使用樣板中的主項目符號格式
- 內文頁使用樣板中的第二層項目格式
- 主章節文字會有超連結，可跳到對應章節頁
- 項目過多時會自動分欄，最多三欄，避免文字超出投影片邊界

章節頁會顯示完整目錄結構：

- `目錄` 可點選回主目錄
- 其他章節與內文頁名稱只作為導覽文字
- 目前章節會用粗體標示
- 項目過多時同樣會自動分欄，最多三欄

內文頁會使用樣板內文頁格式：

- 顯示內文頁標題
- 保留可編輯內容區
- 不顯示回主目錄連結

## 驗證規則

產生 PPTX 前，工具會檢查：

- PPT 標題不可空白
- 至少需要一個章節
- 章節名稱不可空白
- 內文頁標題不可空白

產生 PPTX 後，工具會再檢查：

- 檔案可以正常開啟
- 投影片數量正確
- 必要文字存在
- 主目錄連結正確
- 章節頁可回主目錄
- 投影片尺寸符合樣板

## 注意事項

- 樣板 PPTX 不會被修改。
- 如果指定的樣板缺少 `Contents` 或 `Text` 版面，工具會使用可用版面產生，但視覺效果可能不同。
- 目前工具主要產生架構初稿，不會自動填寫完整教學內容。
- 截圖、箭頭、滑鼠標示等細節仍需在產出的 PPTX 中手動補上。

## 常見問題

### 為什麼主目錄沒有出現我想要的符號？

工具會優先讀取樣板中實際目錄頁的段落符號與縮排格式。如果樣板沒有實際目錄頁格式，才會讀取 master 的 body bullet 樣式。建議用正式教學文件 PPTX 作為樣板。

### 為什麼產生失敗？

請先確認：

- `PPT 標題` 已填寫
- 每個章節都有名稱
- 輸出位置可以寫入
- 樣板 PPTX 檔案存在且可以開啟

### 可以用其他部門的樣板嗎？

可以。點選 `選擇樣板`，指定該部門的 PPTX 樣板即可。工具會從指定檔案讀取版面與目錄段落樣式。
